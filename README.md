# API de locação de jogos contruída com ASP.NET Core

## Status do projeto: Em construção 🏗️

## Sobre o projeto:

Projeto desenvolvido como encerramento da primeira etapa do programa de treinamento do meu estágio como Desenvolvedor Full Stack na CyberGo. Trata-se de uma API para locação de jogos com controle de autenticação e autorização. Na aplicação, usuários administradores podem cadastrar jogos (nome, quantidade, descrição, entre outros atributos), enquanto usuários comuns gerenciam suas locações por meio dos endpoints disponíveis.
